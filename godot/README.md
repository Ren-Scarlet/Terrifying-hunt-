# 暗夜杀机 · Godot 原生迁移版

这是原网页项目的 Godot 原生迁移分支，不会覆盖 GitHub Pages 网页正式版。

## 当前迁移阶段

当前提交建立了可运行的 Godot 原生垂直切片：
- 随机契约开局
- 16 个房间的连通地图
- 8 名幸存者与基础警觉/恐惧/逃跑行为
- 4 点行动点、移动、攻击、倒地、流血倒计时、处决
- 基础卡牌抽取、使用、搜索
- 回合结算与契约目标检查

## 打开方式

安装 Godot 4.7.2，导入本目录中的 `project.godot`，运行主场景。

## 迁移原则

网页版本继续作为规则与内容基准。此处脚本是第一阶段的 Godot 原生实现，尚不代表全部网页功能已迁移。后续需要继续移植正式卡牌、杀手专属能力、完整 NPC 决策、处决地点与 QTE、配件、血网、成就、地图专属规则、存档和正式资源。
