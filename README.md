# 暗夜杀机

《暗夜杀机》是一款单人、房间地图式的策略猎杀游戏。玩家扮演杀手，在有限行动点内探索地图、观察幸存者、运用卡牌与专属能力，并完成系统随机发放的契约。

正式版：https://ren-scarlet.github.io/Terrifying-hunt-/

## 一局怎么玩

1. 在大厅选择杀手并提前构筑卡组。
2. 点击「准备开始 · 随机契约」。
3. 系统此时才随机抽取本局契约；开始前不会展示契约内容，因此不能先看任务再针对性换牌。
4. 进入地图，利用行动点、卡牌、杀手能力和环境完成契约。
5. 完成全部主目标后，可以结算，也可以继续完成额外挑战。

「自由猎杀」是独立的练习模式，不发放强制契约。

## 随机契约

当前契约池包含六种不同主目标：

| 契约 | 主目标 |
|---|---|
| 血色清单 | 击杀 1 名名单指定目标 |
| 无声收割 | 击杀任意 4 名幸存者 |
| 行刑名单 | 完成 2 次处决 |
| 断电协议 | 破坏 2 个区域电闸，并击杀 2 名幸存者 |
| 无声证词 | 击杀名单目标，并阻止幸存者成功报警 |
| 血点献祭 | 达到 200 分，并完成 1 次分数处决 |

每局还会随机附带额外挑战；不同杀手也有自己的专属挑战。

## 基础规则

- 每回合有 4 点行动点（AP），移动、攻击、出牌、搜索和互动会消耗行动点。
- 开局抽取 5 张牌；后续每回合补牌，手牌上限为 6 张。玩家也可以消耗 1 AP 主动抽牌。
- 普通攻击针对站立目标。幸存者倒地后，可以使用普通处决，或抱起搬运。
- 警报达到 60 时会开放逃生点；达到 100 时进入最终危机阶段。所有幸存者成功逃离会导致杀手失败，逃离人数也会影响评分。
- 地图上的固定障碍只出现在指定房间。幸存者只能在仍保留原有障碍木板的房间放下木板；放置后房间会橙色高亮。玩家靠近后可花费 1 AP 破坏。
- 幸存者会根据各自性格报警、躲藏、寻找武器、救援同伴、寻找补给或处理断电区域。

## 处决系统

三种操作彼此独立，不互相替代：

1. **普通处决**：对当前房间的倒地幸存者使用，消耗 1 AP，立即完成。
2. **地点处决**：先抱起倒地幸存者，再搬运到地图上的指定处决地点，选择地点对应的处决方式。
3. **分数处决**：猎杀评分达到 200 分后，当前房间倒地幸存者头顶会出现独立的「分数处决 · QTE」按钮。点击后进行四位数字 QTE；处决本身消耗 1 AP，并获得基础分数奖励，完美完成 QTE 会再获得额外奖励。

## 当前可用杀手

- 设陷者
- 护士
- 女猎手
- 迈克尔·迈尔斯

每名杀手有独立能力与专属挑战。

## 开发与检查

项目使用 TypeScript、Vite 和浏览器 Canvas / DOM。

```bash
npm install
npm run dev
```

常用检查：

```bash
npm run typecheck
npm run check
npm run build
```

## 项目原则

- 契约由系统在开始时随机发放，不提供任务预览或任务选择。
- 卡组在大厅提前构筑，契约不反向决定卡组。
- 玩法规则以当前代码和游戏内提示为准，旧版说明不再作为规则依据。
