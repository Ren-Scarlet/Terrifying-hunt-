# 暗夜杀机 Windows 单机版

本目录是现有《暗夜杀机》浏览器游戏的 Electron 桌面外壳，不重写游戏逻辑。

## 本地构建

需要 Windows 10/11、Node.js 20 或更高版本。

在仓库根目录执行：

```bash
npm ci
npm run check
npm run desktop:build
```

构建完成后，安装包和便携版位于仓库根目录的 `release/`：

- `暗夜杀机-...-nsis-x64.exe`：安装版
- `暗夜杀机-...-portable-x64.exe`：便携版（无需安装）

## 单机与存档

- 游戏页面、脚本、图片和音频全部从本地打包文件加载。
- 桌面版启动时不读取 GitHub 云端平衡配置。
- 玩家存档继续使用现有 localStorage 数据结构，由 Electron 本地 Chromium 配置目录持久保存。
- 网页版和 GitHub Pages 的启动方式保持不变。
- 桌面版平衡调整面板隐藏云端同步入口；本地导入/导出仍可用。

第一次启动后可以断开网络继续游玩。当前版本不会自动迁移浏览器中的旧存档；如需迁移，后续可以增加存档导入/导出入口。
