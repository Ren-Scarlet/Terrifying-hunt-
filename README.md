# 暗夜杀机 · NIGHTFALL

一款运行在浏览器里的**单人卡牌猎杀策略游戏**。你不是逃脱者——你是那栋房子里不该存在的东西。接取契约，潜入一栋**每一局都不一样、约 23 间房**的宅子，观察目标、布置猎场、切断通讯与退路，在致命窗口出现时完成猎杀，然后在警察赶到之前撤离。

纯前端实现（Vite + TypeScript + 原生 DOM），无后端、无框架、无追踪，存档写在 `localStorage`。

## 快速开始

```bash
npm install
npm run dev        # http://127.0.0.1:5173
npm run build      # 类型检查 + 生产构建，输出到 dist/
npm run preview    # 预览构建产物
```

### 本地平衡工作台

首页不再显示平衡调整入口。开发时运行 `npm run dev`，在本地地址后添加 `?admin=1`（例如 `http://127.0.0.1:5173/?admin=1`）即可打开卡牌与杀手能力数值工作台。工作台只在开发模式启用，正式 GitHub Pages 不启用调参入口；调好的数值可导出 JSON，再由开发者审核后写入正式数据。未来账号上线后，线上管理后台必须增加服务端管理员身份校验，不能依靠隐藏网址或前端口令保护。

### 改完东西怎么验（不要开浏览器）

```bash
npm run check      # 类型检查 + 规则回归 + 39 局胜率抽样
npm run check:full # 13 份杀手数据 × 8 局，只用于内部回归与平衡抽样
```

纯逻辑改动（卡牌数值、AI 反应、房间连通）跑 `check` 就够了。只有改了 CSS / 布局才需要开浏览器看图，
而且一次截一张就够——反复全屏截图是这类项目里最慢的环节。

## 玩法

**一局 20–22 回合**。每回合 **4 点行动点（AP）**：走路、挥刀、出牌、搜索柜子全都从这一个池子里扣；开局抽 5 张；之后每个新回合只补 1 张并保留原手牌。玩家也可花 1 点行动点主动抽 1 张。手牌上限为 6 张，超过时必须选择弃牌；牌库耗尽会洗回弃牌堆，并让幸存者团队进度 +5。原来「能量」和「行动点」是两套资源，现在合并——想多追几间屋就少出牌，想连砍就别乱跑。

### 击杀是流程，不是一张牌

**基础伤害来自界面左下角的「挥刀」按钮：默认 1 点伤害；幸存者生命值为 4，累计受到 2 点伤害进入受伤，再累计 2 点倒地。**

| 规则 | 说明 |
| --- | --- |
| 消耗 | 每次挥刀 1 点行动点（`ATTACK_COST`） |
| 选目标 | 同屋有多个人时，**直接点那个人**就是砍他；不点就按「标记目标 > 目标 > 平民」自动挑 |
| 不能连砍 | 砍完必须再做一件事——挪一步、出一张牌、用一次能力、搜索一次——才能砍第二刀 |
| 健康 | 累计受到 2 点伤害 → 受伤；受到攻击后会惊慌逃跑 |
| 受伤 | 再累计受到 2 点伤害 → 倒地 |
| 倒地 | 需等待保护期结束后才能处决；「恩赐解脱」是处决手段；也可能被同伴救起（倒地 → 受伤）。撑 3 回合后流血而死 |
| 恶魔附身 | 迈尔斯尾随值满 100 发动，接下来 3 回合**每一刀造成 2 点伤害**（健康者受伤、受伤者倒地） |
| 死亡 | 永久移除，不能治疗也不能救援 |

**卡牌可以通过效果 DSL 影响伤害与目标**，例如增加下一刀伤害、造成指定点数伤害，或选择本局随机标记的血祭品。

**推开门的那一刻就决定成败。** 相邻房间**只看得见轮廓，看不见人**——找人得自己走过去、看脚印、听动静，或者用侦查 / 感知牌。看见你的幸存者会**当场转身就跑**：

| 局面 | 会发生什么 | 你的手段 |
| --- | --- | --- |
| 没打伏击就推门 | **一律照面**：他立刻察觉并转身跑，警觉越高跑得越急（高警觉连跑两间屋） | 跟着地上的**鞋印**追；严格踩对才攒**杀戮**，满 50 每回合多 2 点行动点 |
| 先打**静止隐身**再进门 | 本回合进门不惊动任何人，屋里的人照旧背对着门 | 白砍一刀，拿到先手 |
| 他跑到隔壁、或者被挤在墙角 | 要么花行动点追，要么他退无可退 | **疾速残暴**贴上去（不耗行动点）后再挥刀 |

也就是说「偷袭」和「追击」不是写死的规则，而是两张牌买到的东西——**不打伏击就别指望有人站着让你砍**，不带追击牌就只能硬追。

### 世界跟着你一起动（脚印、动静与杀戮）

**你每做一个动作（走一步 / 出一张牌 / 砍一刀 / 搜索一次），逃跑中的人和正在做事的人也跟着动一格。** 不存在「我走了三步，他还站在上一格等我」。

行动期间每人最多跑 3 间屋（`REACT_MOVE_CAP`）；但结束回合时，仍与你同屋的站立幸存者会额外获得一次逃跑机会，不能靠耗尽其移动次数把受伤目标留在原地连续攻击。

慌乱中的移动会在地板上留下**血丝脚印**（素材 `public/assets/ui/trail.webp`），朝向下一间屋：

- 越新越亮；受伤的人留下的是**血脚印**（更红）
- **只保留最近两次玩家行动**（`TRAIL_ACTION_WINDOW`），不是按回合：跟着走，旧脚印一步步被擦掉；分叉口走错再回头，那条线索已经没了
- 脚印**不受战争迷雾限制**：房间叫什么你还不知道，但鞋印指向哪里，你看得见

**乌鸦动静**：除了感知牌，还有一条不靠技能的找人线索。有人经过某间屋子，那里就会「乌鸦扑棱 / 地板吱呀 / 柜门轻响」，房间上亮起**！动静**角标，日志里也写一句。动静和脚印一样只留最近几次行动（`DISTURBANCE_WINDOW`），走远了就听不见了。老练的幸存者（`sneaky`，主要是带威胁设定的知名角色）**有时**会踮着脚走：不留脚印、也不惊动乌鸦——但不会一直这样，隔几次行动就会露馅。

**杀戮** 是长距离追逐的补偿，但**不替你走路**：

- 只有**严格踩着「上一间屋 → 这一间屋」的脚印**连续追，杀戮才 +25；随便走、或者只是走到某个碰巧有脚印的房间，反而不涨（−20）
- 满 50 后激活：**立刻 +2 行动点，之后每回合也多 2 点**（`FRENZY_AP_BONUS`）。走哪、走几格全由你自己点，不会像瞬移一样一次跳两格
- **砍中人 / 被幸存者击晕 / 被反手推开**，杀戮立刻清零

### 他们也在赶进度（团队目标）

幸存者不是无目标乱晃：每局随机派给每个人一个**目的**（修电闸 / 凑后门钥匙 / 打电话 / 找武器 / 躲起来 / 救同伴），低警觉时会朝目标房间走，到了就做事。

- **蓝框房间**是本局的团队目标点（随机 3 间），谁在那儿做事都会推进资源栏的**他们的进度**，并弄出动静给你线索
- 团队进度分为四个阶段，每完成 25% 就解锁一个阶段；完成第四阶段后，地图上出现按最短路径距离选出的两个最远逃生点。幸存者会分别赶往最近的逃生点，全部逃离后杀手失败
- 有人钻进柜子 / 床底时，点左下角**「搜索」**（1 点行动点）把这间屋翻一遍才能打得到他

如果你只想看地图上有谁，用「黑暗启迪」这类**感知**牌：地图上会浮出**红色人影**——只有影子、没有名字，而且只亮当前这一回合，不会变成常驻全图透视。

### 哪些房间能进

平面图每个房间右上角都有角标：

| 角标 | 意思 |
| --- | --- |
| 你在 | 当前所在 |
| 可进 · N点 | 相邻，N 点行动点就能走进去（绿色边框） |
| 障碍 · 2点 | 储藏室/地下室门口堆着杂物：**多花 1 点撞开**，进去后就正常；破门能力可以直接清掉 |
| 堵门 · N点 | 被幸存者用家具堵住，多花 1 点 |
| 封锁 · 进不去 | 被卡牌/能力锁住，等它解开 |
| 行动点不足 | 相邻，但这一回合走不动了 |
| ！动静 / 目标点 | 有人刚经过 / 他们的团队目标房间 |

障碍房不再可能变成「永远走不进去的死路」——以前它们「必须破门才能进」，随机长在角落时整条支路都废了，里面的人也会被堵死。

### 巡逻警员

警察不是可击杀的目标：

- 他循着**新鲜的现场**（两回合内的击杀/报警）追你，没有新动静就挨屋搜查
- 同屋连续两回合、且通缉值达到逮捕阈值 → 直接逮捕
- 通缉没满时同屋只是「擦肩而过」：通缉 +1，然后他会离开
- 想甩掉他：压低通缉、制造假现场（诱饵房间）、锁门、或者干脆离开这条街

### 幸存者不是靶子：六种可叠加的行为原型

| 原型 | 发现杀手后做什么 |
| --- | --- |
| 警觉型 | 逃跑、喊叫通知同伴、往出口或电话跑 |
| 反抗型 | 去厨房/车库找刀，找到后正面挡门；跑不掉就推家具堵门 |
| 求救型 | 找电话（书房/大厅）或无线电（地下室）报警，报警让通缉 +3 |
| 救援型 | 优先去救倒地的同伴，其次治疗受伤的人 |
| 躲藏型 | 钻进衣柜/床底，不搜出来就看不见 |
| 英勇型 | 找武器、把同屋的人警觉抬起来，组织反抗 |

每个人开局就带一个**目的**（打电话 / 出口 / 躲藏 / 聚人 / 找武器 / 帮忙），性格决定他怎么实现这个目的。行为可以叠加：一个反抗型也会在倒地同伴旁边选择先救人。

### 幸存者是团队，不是散沙

- 看见杀手、看见尸体、听见喊声，都会抬高**个人警觉**，目击者还会把消息传给隔壁房间。
- **团队警戒 0–100**（顶栏那条红色细条）代表整栋房子的紧张程度：杀人 +7、打倒地 +4、有人报警 +15、有人逃走 +10，没人被惊动时每回合 −6。**拉满直接判负。**
- 团队警戒越高，幸存者行动越积极：低警觉时他们在翻抽屉，高警觉时会成群地跑、堵门、找人、报警。
- 反制手段是**隔离、剪线、制造噪声**：先把人分开再动手。剪掉电话线（`cut_line`）不仅会打断电话报警，还会限制跨区域救援协调；无线电未被破坏时仍能有限协调，电话与无线电都失效后，幸存者只能响应同屋或相邻房间的呼救。再用诱导牌把人引到你想要的位置。

### 你必须管理的五种威胁

| 威胁 | 幸存者的做法 | 你的反制 |
| --- | --- | --- |
| 逃生 | 跑到后院，撑一回合翻篱笆消失 | 锁门、钉死后院（`block_gate`）、在出口守一个回合 |
| 报警 | 找电话/无线电，报警让通缉 +3 | 剪电话线、破坏无线电、先处理求救型 |
| 救援 | 把倒地的人救起来 | 隔离、钉住（`pin`）、守尸 |
| 反抗 | 找武器、堵门、正面挡你一步 | 提前清掉厨房/车库的武器，或用 `break_in` 撞门 |
| 躲藏 | 钻柜子、床底 | 搜寻类卡牌点亮房间，或直接把柜子所在房间翻一遍 |

**任务失败条件**：团队警戒拉满 / 逃走人数超过上限 / 名单目标全部脱岗 / 通缉值超阈值被逮捕 / 天亮（回合用尽）。

### 环境事件：每一夜都可能变调

每三回合触发一次随机环境事件：雷雨会掩盖动静并降低暴露度；照明短暂闪断会让关联区域陷入黑暗；电话铃声可能引出求救者；玻璃碎裂会在地图留下短时声响线索，并惊动附近的人。临时闪断会自动恢复，不等同于玩家破坏电闸。

### 房子每一局都不一样

开局时 `buildLayout()` 会重排整栋房子：

- 在 16×12 的基础空间中递归切分出 23 个不同面积的矩形房间——小房间、普通房间和开阔区域混合出现；户型、走廊长度、哪些房间挨着，每局都不同。
- 房间之间的门不是「相邻就通」：先用随机生成树连起来，再开少量环路。所以房子有长走廊、有绕圈、也有死胡同。
- **后院只挂在最远的那间叶子房上**，而车库就在门内侧：撤离的门和幸存者翻篱笆的地方是同一处，守住后院既是防逃跑，也是保退路。
- 最远的两间房平均要跨 **7 步**，从大厅摸到后院通常得穿过半个屋子。
- 出生点会避开大厅两格以内，不会再出现「推门就撞脸」。

定义在 `src/game/rooms.ts`，`layoutAspect()` 会把当前户型的长宽比交给平面图，房间永远铺满画布。


### 战争迷雾分三层

| 层 | 你看到的 |
| --- | --- |
| ① 未探索 | 只有房间虚线轮廓，不知道里面有什么、有谁 |
| ② 已探索 | 房间结构、家具、门窗等静态信息（**相邻房间也是这一层：看得见名字，看不见人**） |
| ③ 当前视野 | 只有你站着的这间屋、以及被侦查 / 感知临时点亮的房间，才看得见里面的人 |

人物卡上会留一个「?」的残影，标出**他最后一次被看到是在哪间屋子、几个回合前**——这是追踪的全部依据。除此之外，还有两条不靠技能的线索：**地板上的鞋印**和**乌鸦 / 地板响的动静**（房间上的「！动静」角标）。

### 其余

- **通缉值 0–10**：只有**被看见**的击杀才会涨（悄悄做掉的不涨），目击者每回合会续报但收益递减；两回合没有新动静就 −1。警察只追新鲜的现场，找不到你就开始挨屋搜查。**和警察同屋且通缉达到阈值时，他会先盯上你一回合**，这一回合还跑得掉，下一回合还在原地才会被铐走。
- **名单目标开局带线索**：前三回合你知道标记目标在哪（`trackedTurns`），之后就得靠侦查卡、脚印和动静续上——23 间房的迷雾里盲找，任务还没开始就输了。
- **五种任务**：清除名单、无声收割、证据销毁、秘密仪式、替身游戏。每局任务条常驻显示**主目标 / 达成条件 / 失败条件 / 实时进度 / 剩余回合**，最后 5 回合闪红；达成目标才算成功，没达成（超时、目标逃走、被捕、警戒满、**他们的团队进度做满**）直接失败。清除名单与替身游戏都要求**最后撤回车库**，光把人砍完不算完。
- **初期开放 3 位杀手：设陷者、护士、迈克尔·迈尔斯**。其余 10 位资料暂时保留在内部数据中，不会出现在玩家角色选择和公开平衡调整界面，待机制实装后再逐步开放。
- **29 张卡**，按六种战术职责划分：**搜寻 / 诱导 / 破坏 / 封锁 / 潜行 / 追猎**。带商店与牌组构筑（10–15 张，同名最多 3 张）。

## 无障碍显示设置

对局地图工具栏提供三项互相独立的显示设置，并保存在当前浏览器：
- **界面大小**：标准 / 大 / 特大，调整面板留白和主要操作区域。
- **文字大小**：标准 / 大 / 特大，放大地图房间名称、人物、设施、情报与卡牌说明。
- **地图大小**：标准 / 大 / 特大，地图在独立滚动区域内放大，不改变浏览器缩放，也不使用 CSS `zoom`，避免 Canvas 地图坐标错位。

地图上的幸存者头像和设施标记同步放大；地图可以单独滚动查看。 幸存者会根据行为类型沿不同日常路线活动；玩家连续两回合观察同一目标，可确认其常去路线。猎杀机会面板只显示当前视野中真实存在的落单、暗处、习惯停留和设施分心窗口。现场设施情报列出发电机、各区域电闸和电话线路状态。 发电机为区域照明供电，各组电闸控制对应区域的照明分配；玩家可在电闸房间花 1 AP 拉闸或合闸，破坏发电机也会使其供电区域熄灭。现场威胁面板按正在发生的逃生、求救、救援、武装反抗和藏匿行为动态显示，而不是固定罗列无变化的威胁类别。

## 界面怎么读

- **地图是主视区**：重要击杀、破坏、断电、封锁和环境事件会浮现在地图上；猎杀计划显示当前契约重点、已完成准备和当前阶段。
- **底部行动区**：行动点、暴露度、击杀、逃走、团队进度与手牌集中在地图下方；卡牌详情紧贴手牌显示。
- **现场情报抽屉**：幸存者档案、现场设施、威胁面板和完整行动记录集中收纳，默认收起，需要时再展开。
- **环境事件**：每三回合触发一次，改变照明、暴露度或幸存者行动，也可能在地图留下短时声音线索。
- **平面图**：点亮的房间可以走，`？？？` 是还没进去过的，`？` 是某人最后被确认的位置。

```
src/
```

## 平衡调整（不用改代码）

主菜单 →「平衡调整」打开工作台，左边是 29 张卡、右边是当前开放的 3 位杀手能力：

- **卡牌**：直接改费用，改每一条指令的数值（伤害、流血、警戒、锁定回合……），改目标对象、改条件分支里的数值。
- **能力**：改冷却，改每一条指令的数值。
- **保存即生效**。改动写进 `localStorage` 的 `night-hunt-tuning-v2`，刷新后仍然有效；卡牌角上会出现一个「调」字标记。
- **重置**回基线，或者**导出 JSON** 备份；导入时会校验 ID、指令结构、字段和数值范围，非法数据不会覆盖当前配置。

数值改在存档里，原始数据（`data/cards.ts`、`data/killers.ts`）不动，所以「重置」永远能回到出厂值。

## 自己改卡牌效果（不需要 AI）

**卡牌效果全部写在 `src/game/data/cards.ts` 里**，每张卡的 `ops` 是一串指令，引擎逐条执行。
杀手能力在 `src/game/data/killers.ts`，指令清单与字段说明在 `src/game/effect.ts` 开头，
效果解释器位于 `src/game/effects/runtime.ts`；`src/game/engine.ts` 的 `runOps()` 保留为兼容入口，并负责注入游戏运行时依赖。

改数字、加效果、加条件都只动数据文件，存盘刷新就生效。
**只想调数值不想写代码**：主菜单 →「平衡调整」，可改费用、改每条指令的数字、改杀手冷却，
还能导出成 JSON 备份。

举个例子，现在「辣手屠夫」是：

```ts
{
  id: 'shuriken',
  name: '辣手屠夫',
  cost: 1,
  type: 'attack',
  desc: '血迹会说话：所有已经受伤的人，接下来 3 回合位置始终可见。',
  ops: [
    { op: 'track', who: 'injuredAny', turns: 3 },
    { op: 'log', text: '你低头看着地上的血迹——它比他跑得更快。' },
  ],
}
```

想让它同时压一点团队警戒、再抽一张牌，就往 `ops` 里继续加：

```ts
  ops: [
    { op: 'track', who: 'injuredAny', turns: 3 },
    { op: 'alarm', amount: -4 },                 // 附带压低 4 点团队警戒
    { op: 'if', cond: { c: 'killsThisTurn', gte: 1 },
      then: [{ op: 'draw', amount: 1 }] },       // 本回合已杀过人则再抽一张
  ],
```

**可选对象（who）**：`victim`（当前房间最优先的一人）、`lowestHpHere`、`highestAlert`（全场）、`targetsHere`、`civilsHere`、`allHere`、`markedAny`、`allAny`、`fleeing`、`randomAny`、`downedHere`（当前房间倒地的人）、`downedAny`（全场倒地的人）、`injuredAny`（受伤的人）。

**可用指令（op）**：

- 生死：`damage` / `down`（直接打到倒地）/ `execute`（处决倒地目标）/ `kill` / `heal` / `rescue`（倒地 → 受伤）/ `bleed` / `pin` / `stun` / `block`
  - **注意**：卡牌现在一律不写 `damage` / `bleed`——伤害统一走「挥刀」按钮，卡牌只做功能。杀手能力不受这条限制。
- 情报：`scout`（临时视野，可指定全图）/ `pulse`（全场红色人影，只亮这一回合）/ `search`（搜出藏在柜子里的人）/ `track`（标记行踪，位置不再消失）/ `reveal`
- 局势：`alarm`（团队警戒 ±）/ `wanted` / `wantedHalf` / `alert` / `lure`（把人引到指定房间）/ `sabotage`（剪电话、断电、封门）/ `silenceAlarm`
- 潜行与追击：`ambush`（本回合进门不惊动任何人）/ `pursue`（立刻贴到目标房间，不计行动点）
- 自身：`move` / `teleportPlayer` / `steps` / `energy` / `draw` / `discount` / `bonusDamage`（下一刀更重）/ `arrestThreshold` / `evidence` / `stalk` / `lockRoom`
- 流程：`flag` / `log` / `if`

完整的字段说明、可用条件（cond）和全局开关（flag）都写在 **`src/game/effect.ts` 文件开头**。

**防止空放**：给卡加一个 `precheck`，条件不满足时既不扣能量也不弃牌：

```ts
  precheck: { cond: { c: 'victimHere', maxHp: 2 }, hint: '当前房间没有生命值不高于 2 的目标。' },
```

## 视觉与场景渲染

平面图不是一张背景图，而是叠在 DOM 房间下面的 Canvas 场景层（`src/ui/scene.ts`）。静态材质、家具配置与家具绘制分别维护在 `src/ui/scene/materials.ts`、`config.ts` 和 `props.ts`。DOM 只保留房间名、人物头像和点击热区，`rooms.ts` 里的百分比矩形一个都没动，所以交互位置、碰撞和存档完全不受影响。

三层画布：

| 层 | 内容 | 重绘时机 |
| --- | --- | --- |
| `static` | 屋外院子、地面材质、家具、墙体、门窗、血迹、未探索房间的黑幕 | 尺寸变化 / 有人死亡 / 房间被封锁 / 有人越过迷雾边界 |
| `dark` | 全局压暗，再用 `destination-out` 逐光源打光洞 | 每帧（半分辨率） |
| `main` | 静态图 + 黑暗层 + 加色光 + 尘埃 | 每帧 |

几条刻意的取舍：

- **整栋房子当成一个实体画。** 地基阴影只投一次，房间之间的缝隙填成连续墙体，靠邻居的边扩到缝隙中线，朝屋外的边扩出墙厚。逐房间各投一次影，无论材质多细都会读成"十五张漂浮的卡牌"。
- **门不挖洞。** 从墙体上 `destination-out` 挖洞会露出画布底层，颜色不可控；改成在整块墙上盖一条门洞地面 + 门框 + 门轴暗影，既稳定又更像真的门洞。斜对角的邻居（走廊↔地下室）墙上没有洞，只在走位上连通。
- **压暗层负责照明，加色层只负责色温。** 只靠加色光叠亮度会把暗场景冲成灰白；先用光源在黑暗层上"擦"出被照亮的区域，再加一点暖/冷的光色，对比度才留得住。
- **每间房有独立的材质、色调和环境光。** 大厅暖木 + 吊灯，厨房冷瓷砖 + 日光灯，地下室湿水泥 + 单只灯泡，卧室地毯只有月光。
- **未探索的房间直接盖上黑幕。** 只留一圈虚线轮廓，连灯泡的暖光都不画——否则玩家能从天花板的光斑推断屋里有灯、进而推断有家具。
- **未探索的房间直接盖上黑幕。** 只留一圈虚线轮廓，连灯泡的暖光都不画——否则玩家能从天花板的光斑推断屋里有灯、进而推断有家具。
- **UI 不描亮边。** 房间的 DOM 边框只保留极淡的一圈和悬停高亮；画在 Canvas 上的墙已经是实体，再描一圈亮边就又变回卡牌。

场景里没有位图素材，全部是 Canvas 程序化绘制（木地板、瓷砖、水泥、草地、50+ 种家具、血迹、雾与尘埃）。角色头像、卡牌图标、杀手立绘仍使用 `public/assets` 下已有的图片。

## 场地物品（道具箱 / 发电机）

- **道具箱**：每局 2 个，每个 3 件补给。幸存者路过时会按局势挑一件——医疗包（救人）、工具箱（修发电机翻倍）、信号弹（拉高团队警戒）、后门钥匙（直接推团队进度）、防身武器（反击多扣行动点）、烟雾弹（抹掉脚印与视线）。杀手用不了，但可以花 1 点行动点砸烂；砸烂后这个箱子永久失效。
- **发电机**：每局随机 1~2 台。幸存者站在这里会把修复进度推到 100%，满一台直接给团队进度一大截。杀手破坏会扣 45% 修复进度、停机 2 回合；已经通电的还会让团队进度倒退 22。
- 破坏会惊动乌鸦、留下动静，所以「先砸哪个、什么时候砸」本身就是取舍。规则仍然不写死在引擎里：幸存者拿什么、怎么用，由道具与局势决定。


### 幸存者团队与伤害机制

- 团队目标进度分为四段，每 25% 完成一段；已完成阶段不会因破坏设施而倒退。
- 第四阶段完成时，按房间图最短路径距离选出相距最远的两个房间作为逃生点。所有存活幸存者都会转向这两个位置，全部逃离后杀手失败。
- 每局随机标记一名幸存者为血祭品。它只是身份标记，可由卡牌/能力通过 `who: 'bloodSacrifice'` 单独选择，不自动附带属性效果。
- 幸存者生命值为 4：受到 2 点伤害进入受伤，再受到 2 点伤害倒地。默认攻击造成 1 点伤害，卡牌/能力可增加伤害。

## 新增玩法：组合契约与区域供电

每局会随机生成 3 项契约目标，包含击杀幸存者、击杀指定幸存者、进行处决、阻止幸存者成功报警、破坏区域电闸等条件；所有目标完成才算契约成功。地图中的区域电闸独立于发电机，破坏后会切断其关联房间的照明。照明区域会提高幸存者警觉，并让正在执行团队目标的幸存者加快进度。

倒地幸存者可以被抱起搬运；跨越 3 间房后会挣脱并恢复受伤状态，玩家被打断时也会挣脱。厨房提供冰箱与微波炉两种地形处决，各额外奖励 35 分。


## 猎杀操作与潜行补充

- **攻击 / 处决分离**：攻击只针对站立目标；幸存者倒地后可立即花 1 AP 处决。若杀手选择暂时放过，其他幸存者仍可赶来救援，倒地者也会继续流血倒计时。
- **察觉与黑暗**：低警觉幸存者遇到杀手先观察和怀疑；警觉达到 75 才会因玩家进入房间而立即逃跑。黑暗区域会显著降低进入时的警觉增长。
- **人物档案**：点击地图或档案列表中的人物查看背景、习惯、秘密、行为类型、目标、警觉、状态和位置。
- **界面位置**：回合、行动点、暴露度、尾随值等集中在地图下方；现场情报抽屉移到地图与行动区之间。
- **地图设施标记**：道具箱、发电机、照明、电闸、处决点、图腾、柜子和障碍使用更大的图标并显示文字标签。


## 猎杀风格评价与重玩奖励

任务结算除契约总分外，还会单独评估猎杀风格（C / B / A / S）。评价参考目标习惯观察、环境干预、捕兽夹触发、专属能力命中、地形处决、警报与暴露度、剩余回合、无目击猎杀和策略多样性。胜利时按风格等级额外获得血点：B +12、A +25、S +40；失败仍会显示风格评价，但不会获得胜利奖励。不同杀手可以通过不同方式取得高评价，不强制要求全程潜行。
