# 夜猎档案 · Night Hunt Dossier

一款运行在浏览器里的**单人卡牌潜行游戏**。你不是逃脱者——你是那栋房子里不该存在的东西。接取契约，潜入一栋**每一局都不一样、约 15 间房**的宅子，收集情报、控制局势、把目标追到倒地再处决，然后在警察赶到之前撤离。

纯前端实现（Vite + TypeScript + 原生 DOM），无后端、无框架、无追踪，存档写在 `localStorage`。

## 快速开始

```bash
npm install
npm run dev        # http://127.0.0.1:5173
npm run build      # 类型检查 + 生产构建，输出到 dist/
npm run preview    # 预览构建产物
```

### 改完东西怎么验（不要开浏览器）

```bash
npm run check      # 约 3 秒：类型检查 + 11 条规则回归 + 39 局胜率抽样
npm run check:full # 12 杀手 × 8 局，只用于最终平衡
```

纯逻辑改动（卡牌数值、AI 反应、房间连通）跑 `check` 就够了。只有改了 CSS / 布局才需要开浏览器看图，
而且一次截一张就够——反复全屏截图是这类项目里最慢的环节。

## 玩法

**一局 18–20 回合**。每回合 3 点能量、4 步移动；回合结束弃掉手牌并重抽 5 张。

### 击杀是流程，不是一张牌

| 状态 | 规则 |
| --- | --- |
| 健康 | 受到 1 点伤害 → 受伤 |
| 受伤 | 再受 1 点伤害 → 倒地；受伤的人会立刻中断手上的事往反方向跑 |
| 倒地 | 不会自己死。可以补刀处决，也可以被同伴救起（倒地 → 受伤）。撑 3 回合后流血而死 |
| 死亡 | 永久移除，不能治疗也不能救援 |

伤害**只推进一档**：不存在「一张牌秒人」。想杀一个人，至少要走完 健康 → 受伤 → 倒地 → 死亡（或用带 `execute` 的牌在倒地时处决）。

**推开门的那一刻就决定成败。** 看见你的幸存者会**当场转身就跑**，不会站在原地看着你出牌：

| 局面 | 会发生什么 | 你的手段 |
| --- | --- | --- |
| 他背对着门，还没起疑（警觉 < 30，且没藏着） | 没察觉，你还能走到他背后 | 直接出手，拿到第一刀 |
| 他已经绷着弦（警觉 ≥ 30） | 门一开就冲出去，屋里立刻空了 | **静止隐身**伏击进门：不惊动任何人，白打一刀 |
| 他跑到隔壁、或者被挤在墙角 | 要么花步数追，要么他退无可退 | **疾速残暴**贴上去（不计步数）后再补刀 |

也就是说「偷袭」和「追击」不是写死的规则，而是两张牌买到的东西——不带这两张，就只能硬追。

**倒地之后要主动补刀。** 屋里只剩倒地的人时，攻击牌会自动变成补刀（直接致死）；带 `execute` 的牌是专门的处决手段。

### 幸存者不是靶子：六种可叠加的行为原型

| 原型 | 发现杀手后做什么 |
| --- | --- |
| 警觉型 | 逃跑、喊叫通知同伴、往出口或电话跑 |
| 反抗型 | 去厨房/车库找刀，找到后正面挡门；跑不掉就推家具堵门 |
| 求救型 | 找电话（书房/大厅）或无线电（地下室）报警，报警让通缉 +3 |
| 救援型 | 优先去救倒地的同伴，其次治疗受伤的人 |
| 躲藏型 | 钻进衣柜/床底，不搜出来就看不见 |
| 英勇型 | 找武器、把同屋的人警觉抬起来，组织反抗 |

每个人开局就带一个**目的**（打电话 / 出口 / 躲藏 / 聚人 / 找武器 / 帮忙），性格决定他怎么实现这个目的。行为可以叠加：一个反抗型也会在倒地同伴旁边选择先救人。

### 幸存者是团队，不是散沙

- 看见杀手、看见尸体、听见喊声，都会抬高**个人警觉**，目击者还会把消息传给隔壁房间。
- **团队警戒 0–100**（顶栏那条红色细条）代表整栋房子的紧张程度：杀人 +7、打倒地 +4、有人报警 +15、有人逃走 +10，没人被惊动时每回合 −6。**拉满直接判负。**
- 团队警戒越高，幸存者行动越积极：低警觉时他们在翻抽屉，高警觉时会成群地跑、堵门、找人、报警。
- 反制手段是**隔离、剪线、制造噪声**：先把人分开再动手，剪掉电话线（`cut_line`）让求救型白跑，用诱导牌把人引到你想要的位置。

### 你必须管理的五种威胁

| 威胁 | 幸存者的做法 | 你的反制 |
| --- | --- | --- |
| 逃生 | 跑到后院，撑一回合翻篱笆消失 | 锁门、钉死后院（`block_gate`）、在出口守一个回合 |
| 报警 | 找电话/无线电，报警让通缉 +3 | 剪电话线、破坏无线电、先处理求救型 |
| 救援 | 把倒地的人救起来 | 隔离、钉住（`pin`）、守尸 |
| 反抗 | 找武器、堵门、正面挡你一步 | 提前清掉厨房/车库的武器，或用 `break_in` 撞门 |
| 躲藏 | 钻柜子、床底 | 搜寻类卡牌点亮房间，或直接把柜子所在房间翻一遍 |

**任务失败条件**：团队警戒拉满 / 逃走人数超过上限 / 名单目标全部脱岗 / 通缉值超阈值被逮捕 / 天亮（回合用尽）。

### 房子每一局都不一样

开局时 `buildLayout()` 会重排整栋房子：

- 在 6×3 的网格上随机「长」出一块连通的房间区，再把 15 间房随机塞进去——户型、走廊长度、哪些房间挨着，每局都不同。
- 房间之间的门不是「相邻就通」：先用随机生成树连起来，再开 3 条环路。所以房子有长走廊、有绕圈、也有死胡同。
- **后院只挂在最远的那间叶子房上**，而车库就在门内侧：撤离的门和幸存者翻篱笆的地方是同一处，守住后院既是防逃跑，也是保退路。
- 最远的两间房平均要跨 **7 步**，从大厅摸到后院通常得穿过半个屋子。
- 出生点会避开大厅两格以内，不会再出现「推门就撞脸」。

定义在 `src/game/rooms.ts`，`layoutAspect()` 会把当前户型的长宽比交给平面图，房间永远铺满画布。


### 战争迷雾分三层

| 层 | 你看到的 |
| --- | --- |
| ① 未探索 | 只有房间虚线轮廓，不知道里面有什么、有谁 |
| ② 已探索 | 房间结构、家具、门窗等静态信息，但不显示里面的人 |
| ③ 当前视野 | 这里的人才看得到；你一离开，位置就退回「?」并逐渐失联 |

人物卡上会留一个「?」的残影，标出**他最后一次被看到是在哪间屋子、几个回合前**——这是追踪的全部依据。

### 其余

- **通缉值 0–10**：只有**被看见**的击杀才会涨（悄悄做掉的不涨），目击者每回合会续报但收益递减；两回合没有新动静就 −1。警察只追新鲜的现场，找不到你就开始挨屋搜查。**和警察同屋且通缉达到阈值时，他会先盯上你一回合**，这一回合还跑得掉，下一回合还在原地才会被铐走。
- **名单目标开局带线索**：前三回合你知道标记目标在哪（`trackedTurns`），之后就得靠侦查卡和追踪卡续上——15 间房的迷雾里盲找，任务还没开始就输了。
- **五种任务**：清除名单、无声收割、证据销毁、秘密仪式、替身游戏。
- **13 个杀手**，每人一个每回合可用的主力技 + 一个 3 回合冷却的大招。
- **29 张卡**，按六种战术职责划分：**搜寻 / 诱导 / 破坏 / 封锁 / 潜行 / 追猎**。带商店与牌组构筑（10–15 张，同名最多 3 张）。

## 界面怎么读

- **底部吸附区**：回合 / 能量 / 步数 / 通缉 / 击杀 / 逃走 / 团队警戒 和手牌贴在一起，出牌时不用往上看。
- **右侧从上到下**：信息面板（悬停卡牌看效果、点人物看他的打算）→ 在场人物 → **威胁面板** → 行动日志。
- **威胁面板**是这一版新增的：逃生 / 报警 / 救援 / 反抗 / 躲藏 五条，每条都写清现在有几个人在做、以及你该怎么反制（数字全部从真实状态算）。
- **平面图**：点亮的房间可以走，`？？？` 是还没进去过的，`？` 是某人最后被确认的位置。

## 平衡调整（不用改代码）

主菜单 →「平衡调整」打开工作台，左边是 29 张卡、右边是 13 个杀手的能力：

- **卡牌**：直接改费用，改每一条指令的数值（伤害、流血、警戒、锁定回合……），改目标对象、改条件分支里的数值。
- **能力**：改冷却，改每一条指令的数值。
- **保存即生效**。改动写进 `localStorage` 的 `night-hunt-tuning-v2`，刷新后仍然有效；卡牌角上会出现一个「调」字标记。
- **重置**回基线，或者**导出 JSON** 备份、粘回去导入。

数值改在存档里，原始数据（`data/cards.ts`、`data/killers.ts`）不动，所以「重置」永远能回到出厂值。

## 自己改卡牌效果（不需要 AI）

卡牌和杀手能力的效果都是一串**指令**，写在 `src/game/data/cards.ts` 和 `src/game/data/killers.ts` 里，引擎负责逐条执行。改数字、加效果、加条件都在这两个文件里完成，存盘刷新就生效。

举个例子，现在「辣手屠夫」是：

```ts
{
  id: 'shuriken',
  name: '辣手屠夫',
  cost: 1,
  type: 'attack',
  desc: '对当前房间的一名目标造成 2 点伤害，并使其流血：之后每次回合结束再掉 1 点生命。',
  ops: [
    { op: 'damage', who: 'victim', amount: 2 },
    { op: 'bleed',  who: 'victim', amount: 1 },
  ],
}
```

想让它打 3 点、流血 2 点，就改 `amount`；想再加个效果，就往 `ops` 里再写一条：

```ts
  ops: [
    { op: 'damage', who: 'victim', amount: 3 },
    { op: 'bleed',  who: 'victim', amount: 2 },
    { op: 'wanted', amount: 1 },                 // 附带 +1 通缉
    { op: 'if', cond: { c: 'killsThisTurn', gte: 1 },
      then: [{ op: 'draw', amount: 1 }] },       // 本回合已杀过人则再抽一张
  ],
```

**可选对象（who）**：`victim`（当前房间最优先的一人）、`lowestHpHere`、`highestAlert`（全场）、`targetsHere`、`civilsHere`、`allHere`、`markedAny`、`allAny`、`fleeing`、`randomAny`、`downedAny`（已经倒地的人）、`injuredAny`（受伤的人）。

**可用指令（op）**：

- 生死：`damage` / `down`（直接打到倒地）/ `execute`（处决倒地目标）/ `kill` / `heal` / `rescue`（倒地 → 受伤）/ `bleed` / `pin` / `stun` / `block`
- 情报：`scout`（临时视野，可指定全图）/ `search`（搜集证据/线索）/ `track`（标记行踪，位置不再消失）/ `reveal`
- 局势：`alarm`（团队警戒 ±）/ `wanted` / `wantedHalf` / `alert` / `lure`（把人引到指定房间）/ `sabotage`（剪电话、断电、封门）/ `silenceAlarm`
- 潜行与追击：`ambush`（本回合进门不惊动任何人）/ `pursue`（立刻贴到目标房间，不计步数）
- 自身：`move` / `teleportPlayer` / `steps` / `energy` / `draw` / `discount` / `bonusDamage` / `arrestThreshold` / `evidence` / `stalk` / `lockRoom`
- 流程：`flag` / `log` / `if`

完整的字段说明、可用条件（cond）和全局开关（flag）都写在 **`src/game/effect.ts` 文件开头**。

**防止空放**：给卡加一个 `precheck`，条件不满足时既不扣能量也不弃牌：

```ts
  precheck: { cond: { c: 'victimHere', maxHp: 2 }, hint: '当前房间没有生命值不高于 2 的目标。' },
```

## 视觉与场景渲染

平面图不是一张背景图，而是叠在 DOM 房间下面的 Canvas 场景层（`src/ui/scene.ts`）。DOM 只保留房间名、人物头像和点击热区，`rooms.ts` 里的百分比矩形一个都没动，所以交互位置、碰撞和存档完全不受影响。

三层画布：

| 层 | 内容 | 重绘时机 |
| --- | --- | --- |
| `static` | 屋外院子、地面材质、家具、墙体、门窗、血迹、未探索房间的黑幕 | 尺寸变化 / 有人死亡 / 房间被封锁 / 有人越过迷雾边界 |
| `dark` | 全局压暗，再用 `destination-out` 逐光源打光洞 | 每帧（半分辨率） |
| `main` | 静态图 + 黑暗层 + 加色光 + 尘埃 | 每帧 |

几条刻意的取舍：

- **整栋房子当成一个实体画。** 地基阴影只投一次，房间之间的缝隙填成连续墙体，靠邻居的边扩到缝隙中线，朝屋外的边扩出墙厚。逐房间各投一次影，无论材质多细都会读成"十五张漂浮的卡牌"。
- **门不挖洞。** 从墙体上 `destination-out` 挖洞会露出画布底层，颜色不可控；改成在整块墙上盖一条门洞地面 + 门框 + 门轴暗影，既稳定又更像真的门洞。斜对角的邻居（走廊↔地下室）墙上没有洞，只在走位上连通。
- **压暗层负责照明，加色层只负责色温。** 只靠加色光叠亮度会把暗场景冲成灰白；先用光源在黑暗层上"擦"出被照亮的区域，再加一点暖/冷的光色，对比度才留得住。
- **每间房有独立的材质、色调和环境光。** 大厅暖木 + 吊灯，厨房冷瓷砖 + 日光灯，地下室湿水泥 + 单只灯泡，卧室地毯只有月光。
- **未探索的房间直接盖上黑幕。** 只留一圈虚线轮廓，连灯泡的暖光都不画——否则玩家能从天花板的光斑推断屋里有灯、进而推断有家具。
- **未探索的房间直接盖上黑幕。** 只留一圈虚线轮廓，连灯泡的暖光都不画——否则玩家能从天花板的光斑推断屋里有灯、进而推断有家具。
- **UI 不描亮边。** 房间的 DOM 边框只保留极淡的一圈和悬停高亮；画在 Canvas 上的墙已经是实体，再描一圈亮边就又变回卡牌。

场景里没有位图素材，全部是 Canvas 程序化绘制（木地板、瓷砖、水泥、草地、50+ 种家具、血迹、雾与尘埃）。角色头像、卡牌图标、杀手立绘仍使用 `public/assets` 下已有的图片。
